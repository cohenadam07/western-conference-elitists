## What the endpoint returns

`https://site.api.espn.com/apis/v2/sports/football/college-football/standings?season=2026&group={groupId}`, fetched 2026-11-10 09:38 local time.

- Top-level keys: `uid, id, name, abbreviation, shortName, parent, isConference, standings, children, season, links, seasons`; `standings` keys: `id, name, displayName, links, season, seasonType, seasonDisplayName, entries`; each entry: `team, stats`.
- Each entry has 91 stats. Names repeat, so they must be keyed by `type`. Unprefixed types: `gamesbehind, leaguewinpercent, playoffseed, pointdifferential, pointsagainst, pointsfor, streak, wins, divisionlosses, divisionties, divisionwins, lockeddivrank, total, homerecord, awayrecord, vsdivision, vsconf, vsaprankedteams, vsusarankedteams`. The same block repeats with the prefixes `awayrecord, homerecord, vsaprankedteams, vsconf, vsdivision, vsusarankedteams`.
- Order fields that exist: `playoffseed` (and `vsconf_playoffseed`), `gamesbehind`, `leaguewinpercent`, and `team.rank` (a national poll rank; the response does not say which poll). There is no stat called `rank` or `seed`, and the entries carry no explicit position other than their order in the list.
- Records: `total` (`summary` = overall W-L) and `vsconf` (`summary` = conference W-L).
