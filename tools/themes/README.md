# Sport themes

One look per sport, so a page about college basketball reads as College Basketball Savant, an NBA page as
Basketball Savant and a football page as Football Savant, and a new page gets that look by reading files here
instead of copying a stylesheet. Built Nov 6, 2026.

## What is here

| file | what it is | who reads it |
|---|---|---|
| `college/tokens.css` | College Basketball Savant's tokens: colours, the percentile scale, type, sizes, spacing, radii, bar height and hatching. Its own bytes, cut out of its page-src. | College Basketball Savant, College Basketball Coaching Savant |
| `college/fonts.html` | its Google Fonts link | both |
| `nba/tokens.css`, `nba/fonts.html` | the same tokens with Basketball Savant's values | `preview.py` |
| `football/tokens.css`, `football/fonts.html` | the same tokens with Football Savant's values | `preview.py` |
| `nba/chrome.css`, `football/chrome.css` | the few frame rules a theme changes beyond tokens (football's grass ground needs light ink on the wordmark and sidebar; square corners; the hard shadow) | `preview.py` |
| `shared/base.css` | box sizing, body type, links, focus ring, the visually-hidden class | both college pages |
| `shared/frame.css` | the framed sheet: brand, top bar with search, the collapsible left sidebar, the sheet itself | both college pages |
| `shared/frame-narrow.css` | the frame on a phone (sidebar becomes a bottom bar), College Savant's own rules copied line for line | College Basketball Coaching Savant (College Savant has them in its own last `@media` block) |
| `shared/sidebar.js` | the sidebar's collapse button, the `[` shortcut and the remembered state (`cbs-nav`, shared by both college pages) | both college pages; needs `$` defined first |
| `shared/coaching-skin.css` | the coaching pages' components (identity card, percentile rows, tables, tiles, tooltip) painted in whatever theme is loaded | College Basketball Coaching Savant, the NBA preview |
| `preview.py` | builds what the NBA and football themes would look like on their coaching pages, without publishing anything | by hand |
| `check.mjs` | `npm run check:themes` | `check:savant` |

Every theme defines the same token names, so anything written against the tokens runs on any sport.

## How a page uses a theme

Pages built from a page-src folder list theme files in their assembler's `ORDER` as `theme:<path>`
(`tools/savant-cbb/assemble.py`, `tools/savant-cbcoaching/assemble.py`). Order matters: tokens, base, frame,
then the page's own CSS, then any skin. The page's markup supplies the frame's elements (`.app`, `.brand`,
`.nav`, `.top`, `.main`, `.view`, `.foot`); copy them from either college page.

## The rules

- **The flagships are the source.** College's tokens are College Savant's own bytes, so its page cannot drift
  from its theme (`check:page-src` fails on one byte). NBA and football tokens marked `/* = --x */` are the
  flagship's own `--x`, and `check:themes` fails if the flagship changes and the theme does not. The other NBA
  and football tokens are derived: the flagships have no frame to read them from.
- **Basketball Savant and Football Savant are not built from these files.** They are generated by their own
  build scripts (`~/Basketball-Savant/build_page.py`, `pipeline/football`); the themes imitate them and the check
  holds the imitation to them. Moving those builds onto the themes is a separate job.
- **The two coaching pages that are not college are untouched.** `preview.py` shows the NBA and football themes
  on them for Adam's approval; `COLLEGE-BASKETBALL-COACHING-SAVANT.md` lists the differences.

```
python3 tools/themes/preview.py public      # writes public/_preview-*.html; delete them after
```
